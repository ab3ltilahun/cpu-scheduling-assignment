# cpu-scheduling-assignment
First Come First Serviced (FCFS) algorithm
The process that comes first will be executed first. it is Not preemptive(The first job is allowed to run 
as long as it wants to be executed.).It is easy to understand and equally easy to program. In this 
algorithm processes are assigned the CPU in the order they request it. Basically, there is a single 
queue of ready processes. When the first job enters the system from the outside , it is started 
immediately and allowed to run as long as it wants to. As other jobs come in, they are put onto the 
end of the queue. When the running process blocks, the first process on the queue is run next.
