# cpu-scheduling-assignment
Shortest-Job-First (SJF) scheduling
When CPU is available, it will be assigned to the process with the smallest CPU burst (non 
preemptive).If two processes have the same next CPU burst, FCFS is used. When several equally 
important jobs are sitting in the input queue waiting to be started, the scheduler picks the shortest 
job first. Shortest job first is provably optimal when all the jobs are available simultaneously.
