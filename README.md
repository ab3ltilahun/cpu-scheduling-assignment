# cpu-scheduling-assignment
Shortest-Remaining-Time-First (SRTF)
It is a preemptive version of the Shortest Job First Algorithm.It allows a new process to gain the 
processor if its execution time is less than the remaining time of the currently processing one.When 
a new job arrives, its total time is compared to the current process' remaining time. If the new job 
needs less time to finish than the current process, the current process is suspended and the new job 
started.
